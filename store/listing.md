## Short summary (MakerWorld "Summary", ~150 chars)

A chess set where every piece is part of the AI stack: neuron pawns, GPU rooks, MCP-connector knights, terminal bishops, a context-window queen and a model king.

## Description

Every piece is a piece of the AI stack, and its rank on the board matches its importance. There is no text on any piece; the shape tells you what it is.

**The pieces**
- **King = the model.** A small neural network (input, hidden and output layers) on a body with circuit traces. Everything exists to protect it.
- **Queen = the context window.** A window slides up a spiral ribbon of tokens: tokens below are faded, tokens inside the window are raised, and a cursor marks the next one. The most powerful piece: what the model can see at once.
- **Bishop = the terminal agent.** A terminal window with a `>_` prompt and window buttons. It moves far in a straight line, like an agent working through a codebase.
- **Knight = the MCP connector.** A horse head with plug-prong ears, a cable mane and a socket in the neck. It jumps to places nothing else reaches, as MCP plugs a model into any tool.
- **Rook = the GPU.** A tower of cooling fins and fans. The heavy compute that holds the corners.
- **Pawn = the neuron.** A cell body with dendrites. Many small units that add up.

All pieces stand on a microchip base with pins and traces.

**Printing**
- Printed and checked for a Bambu Lab P1S, and it works on any printer with a 180 x 180 mm bed or larger.
- Every piece is one solid part. Pieces are designed with 45° overhangs, so they print without supports. Each file was checked slice by slice for mid-air starts, thin necks and thin walls.
- Print one set in white and one in black (or any two colours).
- A full side (16 pieces) fits on one plate: use `plate_plain_16_pieces.stl`, or print pieces one by one.

**Files**
- `king_plain.stl`, `queen_context_plain.stl`: 1 each per side
- `bishop_terminal_plain.stl`, `knight_mcp_plain.stl`, `rook_gpu_plain.stl`: 2 each per side
- `pawn_neuron_plain.stl`: 8 per side
- `plate_plain_16_pieces.stl`: a whole side on one plate

**Open source.** The generator is open source (Python + manifold3d): https://github.com/GIAMAT13/chess-set-ai

## Print settings (paste into "Print settings" / "Print profile notes")

| Setting | Value |
|---|---|
| Printer | Bambu Lab P1S (any printer, 180 x 180 mm bed or larger) |
| Nozzle | 0.4 mm |
| Layer height | 0.16 mm (detail) or 0.2 mm (faster) |
| Walls | 3 |
| Infill | 15% gyroid |
| Supports | none, or tree supports "touching build plate only" for a cleaner knight jaw |
| Brim | not needed; use a 3 mm brim for the king and queen on a cold or dusty plate |
| Material | PLA or PETG |
| Scale | 100% (king is about 86 mm tall) |
